# gene-function-data

Generated data for the Schnable Lab [Gene Function Summaries](https://schnablelab.org/tools/gene-function-summaries/)
lookup tool (maize, sorghum and rice; GeneAnnotation v2). GitHub Pages serves it at
https://schnablelab.org/gene-function-data/.

Do not edit by hand. The files are written by `scripts/generate_gene_function_summaries.py` in
[jschnable.github.io](https://github.com/jschnable/jschnable.github.io) and published with
`scripts/publish_gene_function_data.sh`, which replaces this repository's history with a single commit
on each update so old data versions do not accumulate.
